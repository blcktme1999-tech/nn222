# 筆記本

這份是給下一個任務看的現況，不是官網改版紀錄。現有刑事警察局網站不要改。通用版在 `通用系統/`。

## 要留下的功能

- 案件查詢：用姓名、證號查出案件。介面是 `通用系統/case-query.html`，資料走 `POST /api/citizen/query`。
- 公文：從查詢結果點一筆進來。介面是 `通用系統/documents.html`，讀 `sessionStorage` 的 `plain-document`。表欄是案號、狀態、案件、公文、內容、附件。沒有建立時間。附件在同一頁預覽，不另開頁。
- 線上報案：現有線上筆錄。介面是 `通用系統/report.html`，沿用 `/public/app.js` 與 `/public/video-session.js`。含視訊、案件訊息、筆錄頁上的公文表。民眾與承辦人都能看公文、傳訊息。視訊小畫面固定，不跳頁。
- 通緝：系統裡的通緝資料，不是官網通緝專區。查詢走 `POST /api/wanted/query`。建立與列表要承辦人登入，走 `POST /api/staff/login` 與 `/api/wanted`。

## 不要帶過去的東西

- 刑事警察局頁首、頁尾、背景、局徽、官網選單。
- 官網首頁、跑馬燈、新聞、頁尾二維碼。
- 公文表的建立時間。

## 資料從哪裡來

登入、案件、附件、視訊、通緝仍用現在這套 API 與資料庫。通用版只換外觀，不另做一份資料。
